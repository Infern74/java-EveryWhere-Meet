# EveryWhere Meet — сервис для организации мероприятий

**Backend-часть платформы для поиска и участия в событиях (аналог Meetup).**  
Проект построен по принципам микросервисной архитектуры с использованием современных практик CI/CD.

---

## 🚀 Функциональные возможности

### Основной сервис (`ewm-service`)
* **Управление событиями:** создание, модерация, публикация, поиск по фильтрам
* **Система участия:** отправка запросов, подтверждение/отклонение заявок
* **Категории и локации:** гибкая система классификации событий
* **Валидация:** комплексная проверка данных на всех этапах

### Сервис статистики (`stats-server` + `stats-client`)
* **Сбор метрик:** учет просмотров событий
* **API для аналитики:** получение статистики по временным интервалам
* **Интеграция:** отдельный микросервис с собственной БД

---

## 🛠 Технологический стек

* **Backend:** Java 11, Spring Boot 2.7
* **Базы данных:** PostgreSQL, H2 (для тестирования)
* **Микросервисы:** Custom REST client (RestTemplate)
* **Контейнеризация:** Docker, Docker Compose
* **Сборка:** Maven
* **Тестирование:** JUnit, Mockito, интеграционные тесты
* **Документация API:** OpenAPI 3.0 (Swagger)
* **Валидация:** Hibernate Validator
* **Утилиты:** Lombok, MapStruct

## 📁 Архитектура проекта
```
java-EveryWhere-Meet/
├── ewm-service/ # Основной сервис (события, заявки, пользователи)
├── stats-server/ # Микросервис статистики (просмотры)
├── stats-client/ # Клиент для интеграции со статистикой
├── stats-dto/ # Общие DTO для работы со статистикой
```

## 🏃 Быстрый старт

### Предварительные требования
- Java 11 или выше
- Maven 3.6+
- Docker и Docker Compose
- PostgreSQL (или использовать контейнер)

### Запуск через Docker Compose (рекомендуемый способ)
```bash
# Клонируй репозиторий
git clone https://github.com/Infern74/java-EveryWhere-Meet.git
cd java-EveryWhere-Meet

# Запусти все сервисы
docker-compose up -d
```
### Ручной запуск
```bash
# Сборка проекта
mvn clean package

# Запуск основного сервиса
java -jar ewm-service/target/ewm-service.jar

# Запуск сервиса статистики
java -jar stats-server/target/stats-server.jar
```
### После запуска:
* Основное API: http://localhost:8080

* Сервис статистики: http://localhost:9090

## 🗄️ База данных
### Основные сущности:
* User — пользователи системы

* Event — события (могут быть в статусах: PENDING, PUBLISHED, CANCELED)

* Request — заявки на участие (PENDING, CONFIRMED, REJECTED, CANCELED)

* Category — категории событий

* Compilation — подборки событий

## 🔧 Ключевые технические решения
* Микросервисная архитектура: разделение на независимые сервисы повышает отказоустойчивость

* Асинхронная обработка: события статистики обрабатываются без блокировки основного потока

* Комплексная валидация: проверка на уровне DTO, сервиса и БД
